Send workouts to Apple Health

Once the Shortcut is installed, tapping Finish in VelociReps opens Shortcuts, which logs the workout in Health and shows Saved to Apple Health. Switch back to VelociReps and you land on the Congratulations screen. That is the whole flow: one tap.

You can finish at any point: after the first set, half way through, or after the whole session. Unfinished exercises and skipped sets never block the send.

1. Install the Shortcut

Download the Shortcut

Open the downloaded file from Safari's Downloads (the arrow icon) or from Files, then tap Add Shortcut. Keep its name exactly VelociReps Log Workout.

If the download does not open in Shortcuts, build it by hand instead. It takes about two minutes:

  1. Open Shortcuts, tap +, and name it VelociReps Log Workout.
  2. Add Get Dictionary Value. Set it to get the value for key startDate in Shortcut Input.
  3. Add Get Dictionary Value again for key durationSeconds in Shortcut Input.
  4. Add Get Dictionary Value again for key energyKcal in Shortcut Input.
  5. Add Log Workout. Set Type to Traditional Strength Training. Set Date to the first Dictionary Value, Duration to the second with the unit set to sec, and Calories to the third in kcal.
  6. Add Show Alert with the text Saved to Apple Health.

You can check the same six steps in the downloaded Shortcut: it has nothing else in it, apart from a check that it was started from VelociReps.

2. Allow Health access

The first time it runs, Shortcuts asks to write workouts to Health. Tap Allow. If you tapped Don't Allow earlier, open Health → your picture → Apps → Shortcuts and turn on Workouts. If it also asks for Active Energy, allow that too.

If iOS asks Open in "Shortcuts"? when you tap Finish, tap Open.

3. Finish a workout

Tap Finish. Shortcuts opens, logs the workout, and shows Saved to Apple Health. Tap OK and switch back to the VelociReps icon on your Home Screen. The workout is saved in VelociReps whether or not Shortcuts finished.

To send a workout later, or again, open it from the history list and use Share → Send to Apple Health. Sending the same workout twice creates two entries in Health, so VelociReps warns before a second send.

To stop sending on Finish, go to Me → Apple Health and tap Stop sending when I tap Finish.

What is sent

One Traditional Strength Training workout: the start time, the active duration in seconds, and the estimated calories. Calories use the app's estimate of six kcal per whole minute. Exercises, reps, weights and notes stay in VelociReps. Health has no field for them through Shortcuts.

Paused time is excluded from the duration, so Health may show an end time earlier than when you tapped Finish on a paused session.

If something goes wrong

Shortcuts says it could not find the shortcut. The name must be exactly VelociReps Log Workout.

Shortcuts shows "Use this from VelociReps". It was run without workout data. Run it from VelociReps, not from the Shortcuts app.

Log Workout fails or asks for a value. Check that the three Get Dictionary Value actions read from Shortcut Input and that Duration uses seconds. Check Health permissions as in step 2.

Nothing happens when you tap Finish. Shortcuts opens only from a tap on an iPhone. Check Me → Apple Health shows sending is on, and send the workout from its Share menu.

Editing a workout in VelociReps after sending does not update the Health entry. Make corrections in Health.
