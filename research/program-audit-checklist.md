# Program Audit Checklist

Use this when reviewing the current routine.

## 1. Inventory The Week

- List every training day.
- For each exercise, note sets, rep target, RIR/failure target, rest, and whether it is supersetted.
- Mark the intended target muscle.
- Mark likely limiting factor: target muscle, cardio, grip, low back, bracing, joint discomfort, skill/technique.

## 2. Count Volume

Create weekly totals with three columns:

- Direct hard sets.
- Indirect partial-credit sets.
- Fatigue cost notes.

Suggested indirect credit:

```text
1.0 = target prime mover, close to failure
0.5 = strong secondary mover, meaningful ROM/tension
0.25 = secondary contribution but probably not limiting
0 = negligible hypertrophy credit
```

Flag muscles with:

- Fewer than about 8 direct sets per week if they are a growth priority.
- More than about 20 total direct sets per week without a clear reason.
- Large indirect fatigue load without matching direct hypertrophy benefit.

## 3. Review Frequency

For each muscle:

- 1x/week: acceptable for maintenance or low priority, but may be inefficient for high volume.
- 2x/week: good default.
- 3-4x/week: useful for specialization, high weekly volume, or muscles that recover quickly.

Flag any muscle getting many sets in one session but little work elsewhere.

## 4. Review Supersets

Good signs:

- Antagonist pairing.
- Non-competing muscles.
- Stable reps/load across rounds.
- No major bracing, grip, or cardio bottleneck.

Red flags:

- Same-muscle pairing used unintentionally.
- Heavy compound paired with another demanding compound.
- Two exercises competing for low back, grip, or bracing.
- Second exercise performance consistently drops for reasons unrelated to the target muscle.

Preferred examples:

- Chest-supported row + machine press.
- Cable curl + rope pushdown.
- Leg extension + leg curl.
- Calf raise + abs.
- Lateral raise + easy curl or pushdown.

Riskier examples:

- Squat + row.
- RDL + pull-up.
- Deadlift + overhead press.
- Barbell row + curl if grip and elbow flexors are already limiting.

## 5. Place Myo-Reps

Good candidates:

- Lateral raise.
- Curl.
- Triceps pushdown.
- Leg extension.
- Leg curl.
- Calf raise.
- Cable fly.
- Machine isolation work.

Poor candidates:

- Squat.
- Deadlift/RDL.
- Heavy barbell row.
- Heavy overhead press.
- Any lift where technique failure creates risk.

Default prescription:

```text
Activation set: 10-30 reps near failure
Mini-rest: 10-30 seconds
Mini-sets: 2-5 reps
Stop: form degrades, reps drop below target, or planned mini-sets complete
```

## 6. Place Lengthened Partials

Use for stable exercises where the lengthened position is safe and loadable.

Default prescription:

```text
Full-ROM reps first
Then 2-6 controlled lengthened partials
Progress full reps before adding load
Do not let partials replace full-ROM progression
```

Flag:

- Joint irritation.
- Partials replacing too many full reps.
- Unclear ROM standard.
- Exercises where the lengthened position cannot be controlled.

## 7. Decide What To Change

For each flagged item, choose one change:

- Move the exercise to a different day.
- Change the superset pairing.
- Convert a same-muscle superset into straight sets.
- Replace a fatiguing compound with a more stable variation.
- Add direct isolation work for an under-served muscle.
- Reduce redundant volume.
- Add myo-reps only to low-risk accessories.
- Add lengthened partials only where full-ROM work is already solid.
