# Current Program (Ryan) — restructured 2026-07-04

Ryan's active training program, kept here so reviews can be grounded against the
research notes in this folder. This is the source of truth for "my current program".

Goal: **upper-emphasis, V-taper** — side delts (top of the V) and lat width are the
priority, chest/arms ride along, legs promoted to **2x/week** as a strong/thick
supporting cast with a resilient posterior chain. Split is **Upper/Lower** (upper 3x,
lower 2x). Style: antagonist/non-competing supersets, myo-reps on low-risk isolation,
double progression `dp()`, **ROM over lengthened partials** (partials optional finisher
on isolations only).

Equipment: see [equipment.md](equipment.md). Cues: see [exercise-cues.md](exercise-cues.md).

## Superset equipment rule (hard constraint)

One pair of SelectTech DBs + one cable stack, so **within a superset the two moves must
use different equipment** (DB / cable / barbell / bodyweight). No DB+DB, no cable+cable,
no barbell+barbell in a superset (would force re-loading every alternation). Separate
straight blocks may reuse equipment at a different weight (finish, rest, re-load, go).
`[BB]` barbell · `[DB]` dumbbell · `[C]` cable · `[BW]` bodyweight.

## Swing variables (bump if a muscle lags)
- Rear delt (~6) and calves (~5.5) are on the lighter side — add a set each if wanted.
- Triceps direct (~8) is modest but gets heavy indirect from 2x benching/incline. Add if arms lag.
- Chest is 2x/week; add one chest superset to Upper B for 3x if desired.

## Resolved from the prior program (PPL) review
- Lower body 1x → **2x/week**; hamstrings ~3 → ~9 sets, glutes ~5 → ~9.
- Back volume trimmed ~24 → ~19 and re-biased toward width (verticals).
- RDL/ab-wheel lumbar interference removed (ab wheel now paired with split squat; hinges are straight anchors).
- Side delts ~7.5 → ~14.5 (biggest V-taper lever), now 3x.
- Front-delt/OHP work dropped (redundant with pressing; nothing for width).
